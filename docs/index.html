What is a Nugget Wallpaper?

Everything you need to know about putting animated wallpapers on your iPhone with the Nugget tool.

A Nugget wallpaper is an animated, motion-based wallpaper for iPhone and iPad that you install using Nugget — an open-source iOS customization utility by LeMinLimez that uses the sparserestore and BookRestore methods to modify Apple devices without a full jailbreak.

Instead of a static image behind your icons, a Nugget wallpaper can move, react and animate across your Lock Screen and Home Screen. The Nugget Wallpaper project hosts a curated library of these motion wallpapers, with live animated GIF previews on every page so you always know what you are installing.

How to install a Nugget wallpaper

Four simple steps from download to a moving Lock Screen.

Pick your wallpaper

Browse the Nugget wallpaper library, watch the animated GIF preview and download the pack.

Back up your device

Connect your iPhone or iPad to a PC and create a full backup. Always back up before using any iOS modification tool.

Apply it with Nugget

Run the Nugget app, load the wallpaper into the PosterBoard feature, and restore your device following the official tutorial.

Enjoy the motion

Your iPhone now runs a true animated wallpaper — pan, swipe and watch it come alive on the Lock Screen and Home Screen.

Safety note: Nugget uses the sparserestore and BookRestore methods and is not compatible with iOS 27 (Apple patched the restore method, and data loss is possible). Only install wallpapers you trust, follow the official guide, and always keep a backup.

Nugget wallpaper FAQ

Quick answers to the questions people ask most about motion wallpapers for iPhone.

What is a Nugget wallpaper?

A Nugget wallpaper is an animated or motion wallpaper for iPhone and iPad that is installed with the Nugget tool. Instead of a static lock-screen image, it can animate and move across your screen — something Apple doesn't offer natively.

What iOS versions does a Nugget wallpaper support?

Nugget wallpapers support iOS and iPadOS 17 through 26, plus generic platforms. Avoid iOS 27 entirely — Nugget's restore method is patched there and data loss is likely.

How do I install a Nugget wallpaper on my iPhone?

Download a wallpaper from the library, run the Nugget tool on Windows or macOS (Linux also works), and apply it via the PosterBoard feature. The full walkthrough is on Nugget Host.

Does installing a Nugget wallpaper require a jailbreak?

No. Nugget works through the sparserestore and BookRestore non-jailbreak methods, so you can add animated wallpapers on a stock iPhone as long as you're on iOS 17–26.

Are there free Nugget wallpapers?

Yes. The library on mwallx.com has both free and premium curated wallpapers, with animated GIF previews for every single one.
